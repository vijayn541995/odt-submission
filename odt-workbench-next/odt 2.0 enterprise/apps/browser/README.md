# Browser App

Browser shell for ODT 2.0 Enterprise.

Target role:

- Vite/React web entry point.
- Consumes shared UI from `packages/ui`.
- Consumes API client from `packages/api-client`.
- Runs against local or remote ODT API.

Current status: scaffold only. The working browser implementation is frozen in `../../frozen-baseline/odt-workbench-next-source`.
